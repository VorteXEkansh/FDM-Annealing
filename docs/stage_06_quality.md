# Stage 6 quality record

The installed environment was inspected from local executable metadata, package
metadata, Workbench template files, host system queries and one MAPDL batch
probe. The product-limit statement is drawn from the official Ansys Student 2026
R1 page. Presence, invocation and entitlement are reported separately.

The MAPDL probe is deliberately non-numerical. It contains no geometry, nodes,
elements, loads, analysis type or solve command. Its exit code, banner and raw
files are preserved with SHA-256 hashes. It confirms only the identified MAPDL
binary and Student Mechanical checkout.

Production automation requires explicit temperature, hold time, fixture gap and
material identity, and refuses execution while any evidence gate remains false.
No full campaign, mesh, field solution, sensitivity calculation, uncertainty
interval or optimization was produced.

The complete 29-page PDF was regenerated and every page was inspected from fresh
110 dpi raster renders. The Stage 6 PDF review file records its exact hash and
all reviewed page numbers.
