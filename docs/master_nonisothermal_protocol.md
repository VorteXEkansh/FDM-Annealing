# Non-isothermal constitutive verification protocol

This is a prescribed material-temperature test of a viscoelastic constitutive adapter, separate from the existing isothermal test and from any physical validation. The original comparison rule, domain and input history were recorded in `coarse_a01/case.json` before a solver was started. After the one-second case, the fixed increment is decreased to 0.1 and 0.05 s (further halving if necessary) without changing the constitutive data or acceptance threshold.

The verification solid measures 10 × 1 × 1 mm and uses one SOLID185 brick, traction-free lateral faces and zero axial displacement on each end. Rigid modes are removed on the two corresponding transverse coordinate planes. Identical normalized bulk/shear spectra imply constant Poisson ratio. Uniform temperature and boundary/loading symmetry give a homogeneous uniaxial stress state, so axial mechanical strain is the negative of the integrated free thermal expansion. Temperature is prescribed in the solid, not equated to a measured oven history. The numerical fixture ramps from 23 to 80 °C at 1 K/s, holds 60 s, returns at 1 K/s to 23 °C and holds a further 60 s, all under restraint. There is no physical fixture, release, thermal gradient or recovery strain in this test. A return to the starting temperature is not a return to the initial viscoelastic state.

`TB,PRONY` uses the 23 source-derived shear and bulk pairs. `TB,SHIFT` with `PLIN` tabulates absolute temperature in kelvin against the common logarithm of the **rate multiplier**, the reciprocal of the source relaxation-time multiplier. Explicit absolute abscissae and `TOFFST,273.15` are used. The reference temperature for strain is 23 °C, distinct from the 65 °C master-curve reference. Table nodes include 65 °C and never extrapolate beyond the 23–85 °C source interval. Only 23–80 °C is exercised. Refinement checks compare both the time increment and shift-table spacing.

An independent scalar integrator uses the exact source piecewise shift function, without the MAPDL table or FE stiffness. For each Maxwell arm, the stress rate equals the branch modulus times the mechanical strain rate minus the branch stress divided by its local relaxation time. On each linear temperature segment the independent integrator freezes the shift at the midpoint and integrates this scalar ODE exponentially; summing all arms and the equilibrium spring gives axial stress. Its result is checked by halving the reference step from 0.001 to 0.0005 s. This is an independent discretization of the same material law, not independent material data. The 26 sample times are load-step endpoints selected in the original case file and include both hot- and cold-hold states. Accuracy refers to those samples only.

Per-sample numerical gate chosen before the first run: absolute axial stress error ≤ 0.0001 MPa + 0.002 times the absolute reference stress. The absolute term prevents an unstable ratio near the zero crossing. For selecting a refined increment the adjacent-pair change is compared with the same mixed gate using the finer magnitude; this is a resolution test, not a production timestep recommendation. Also compare reaction equilibrium to stress times the 1 mm² face area and, in post-coarse checks, the temperature implied by the actual thermal-strain output to the imposed material temperature. Report component mismatches separately. No numerical material coefficient, imposed thermal history or accuracy gate is adjusted to obtain agreement.
